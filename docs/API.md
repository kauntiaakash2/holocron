# API

JSON errors: `{error:{code,message}}`. All results use no-store. Mutating requests require exact `Origin: APP_ORIGIN`; JSON bodies are limited to 24KB. No cross-origin credentials or permissive CORS.

| Method/path                                            | Authorization           | Behavior                                                                                                                                                                                         |
| ------------------------------------------------------ | ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| POST /api/registrations                                | public; throttled       | Idempotency-Key (32–100 URL-safe characters), teamName, members[3], consents, empty website honeypot. 201 committed or replayed; 409 duplicate/key conflict; 422 invalid; 503 closed/unavailable |
| POST /api/registrations/recover                        | secret recovery key     | `{key}` restores private cookie; generic 404 on failure                                                                                                                                          |
| GET /api/registrations/:id                             | private team cookie     | Persisted roster, event identity, status                                                                                                                                                         |
| GET /api/registrations/:id/ticket?format=svg\|png\|pdf | private team cookie     | SVG preview, high-resolution PNG, landscape A4 PDF                                                                                                                                               |
| GET /api/tickets/verify/:token                         | opaque token; throttled | status, teamName, registrationId only; invalid, pending_review, valid, revoked, already_checked_in                                                                                               |
| POST /api/admin/login                                  | provisioned credentials | email/password; 8-hour HTTP-only session                                                                                                                                                         |
| POST /api/admin/logout                                 | session                 | destroys current session                                                                                                                                                                         |
| GET /api/admin/me                                      | organizer session       | account ID, email, role                                                                                                                                                                          |
| GET /api/admin/registrations                           | admin/reviewer          | search/status filters; newest 200; admin-only format=csv export of this exact view                                                                                                               |
| GET /api/admin/registrations/:id                       | admin/reviewer          | private roster; audited                                                                                                                                                                          |
| POST /api/admin/registrations/:id                      | admin/reviewer          | `{action:'approve'\|'flag'\|'revoke'}`; revoke admin-only                                                                                                                                        |
| POST /api/admin/tickets/check-in                       | admin/checkin           | `{token}`; approved only; explicit, atomic, duplicate returns 409                                                                                                                                |

Access errors: 401 login, 403 origin/role, 404 absent or unauthorized registration, 413 large payload, 415 non-JSON, 429 throttle, 503 service unavailable. Internal database details are never returned.
