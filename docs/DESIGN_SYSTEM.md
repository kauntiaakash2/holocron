# Design system

Concept: an unfinished galactic archive. The supplied gold diamond emblem with its blue circular core carries the event identity; the live procedural Holocron remains a separate interactive artifact. Gold marks the archive; cyan marks interactions. Dark navy dominates. The header and ticket logo use the supplied emblem; the preloader uses the user-supplied reference video.

Tokens live in `app/globals.css`: deep space #05070D, midnight #0A1020, charcoal #111723, gold #E5BD65, cyan #55DDF3, primary text #F3F0E7, secondary #B5BDCB. Error text is lightened for dark-surface contrast.

Display: Yatra One (Latin subset), selected to carry the angular, brush-cut character of the supplied Devanagari title reference into English. Main headlines, branding, hero water text and bottom wordmark retain it at its native 400 weight without synthetic bold. Body prose, challenge titles, navigation, buttons, inputs and dense records use Inter; technical labels and sensitive identifiers use IBM Plex Mono. Paragraphs are 15–16px with 1.75–1.8 line height, the mission principle is 18–21px, and brief details are 15px. Main section headings use a responsive 32–52px scale with relaxed spacing. Phone challenge cards stack in one column at 600px and below; tablets use two columns. Navigation labels use Inter 500 at 13px on desktop and 14px on mobile, with 10px indices and existing 44px minimum hit targets. Fontsource packages self-host licensed assets; Yatra One is bundled under SIL OFL 1.1 (copy in public/fonts/YatraOne-OFL.txt). Ticket SVGs outline locally bundled Yatra One branding and DejaVu Sans information text; PDF print instructions embed DejaVu Sans (licenses in public/fonts). The hero’s top-center organizer lockup uses the symbols cropped from the user-supplied AlgoZenith and KodeWreck images, separated by a small ×. The symbols have adjacent name labels, horizontally centered against each logo; AlgoZenith includes a small KIIT Chapter subtitle within its text block. The × stays between the two pairs. Visible text supplies accessible organizer names, so the neighboring images use empty alt text to avoid duplication. Centered flex alignment and optical sizing balance the taller AlgoZenith symbol against the wider KodeWreck mark. AlgoZenith retains its blue; CSS grayscale/inversion gives KodeWreck a light monochrome treatment. Screen blending merges both backgrounds into the dark hero without redrawing the logos. The source images remain preserved; cropped assets live in public/organizers and Next Image serves responsive sizes.

Desktop uses wide margins, a paired hero/artifact, a ruled event strip, and editorial sections. Mobile changes the hero to stacked composition and prioritizes registration fields. Minimum targets are 44px. Ticket art uses independent 1200×720 coordinates.
